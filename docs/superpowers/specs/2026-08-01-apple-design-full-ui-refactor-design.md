# 运维叫号台 Apple Design 全站 UI 重构规格

- 日期：2026-08-01
- 状态：交互原型已确认，等待书面规格复核
- 参考原型：`.superpowers/brainstorm/423-1785569630/content/apple-design-fluid-v2.html`（仅本地设计伴侣使用，不纳入 Git）
- 技术边界：Vue 3 + TypeScript；后端接口、业务规则、角色权限和数据库结构不变

## 1. 目标

将现有深色传统后台界面重构为轻盈、清晰、可预测的 Apple 风格工作界面，并保持运维场景所需的信息密度。重构覆盖登录、工作台、任务、值班、人员、统计、审计、异常页、通知和所有交互层。

完成后的界面必须做到：

1. 用户在任一页面都能明确知道当前位置、可前往区域、当前内容和退出方式。
2. 视觉层级主要依靠字号、字重、间距和灰阶；蓝色仅用于主要动作、链接和焦点。
3. 导航、工具栏和浮层使用有层级意义的半透明材质；普通内容使用实体白色表面。
4. 按钮和可点击行在按下瞬间反馈；任务详情面板可以在运动途中被抓住并反向操作。
5. 桌面端适合深度工作，移动端保留核心流程并满足不小于 44px 的触控目标。
6. 支持减少动态效果、减少透明度和高对比度偏好。
7. 原有权限、校验、状态流转、审计和通知行为不得改变。

## 2. 不在本次范围内

- 不修改 Spring Boot 接口、数据模型、数据库迁移和任务分配规则。
- 不新增业务字段、统计口径、角色或权限。
- 不引入暗色模式；本次以已确认的浅色工作界面为唯一主题。
- 不加入装饰性声音、震动、彩纸或无业务意义的动画。
- 不为追求视觉统一而隐藏必要的流程编号、时间窗口、负责人或审计信息。
- 不替换现有 Vue Router、Pinia、Axios 或测试框架。

## 3. 设计原则

### 3.1 目的与熟悉感

- 保留用户已熟悉的左侧角色导航，不改业务信息架构。
- 导航名称继续使用“工作台”“任务中心”“值班管理”等具体标签，不改成含糊的“首页”“管理”。
- 常用动作在当前对象附近出现；高级筛选和低频管理动作降低视觉权重，但保持可达。

### 3.2 简洁而非隐藏

- 工作台首先显示需要行动的任务，再显示总量和次要信息。
- 同类数据放在一个白色面板内，用细分隔线形成连续列表；不为每一行创建独立彩色卡片。
- 状态颜色只用于小面积状态标识。页面主体保持黑、白、灰，主要动作使用 Apple 蓝。

### 3.3 直接反馈与可中断性

- 按钮、导航项、任务行在 `pointerdown` 时立即缩放或改变表面，不等待 `click`。
- 浮层动画从当前屏幕位置继续，而不是从预设起点重新开始。
- 用户拖动任务详情面板时，面板与指针 1:1 跟随；松手后依据当前位置和释放速度决定关闭或回弹。
- 进入和退出沿相同路径进行。桌面端任务详情从右侧进入并向右退出；移动端从底部进入并向底部退出。

### 3.4 克制的材质

- 左侧导航使用较重的浅色半透明材质，顶部栏使用更轻的半透明材质。
- 任务列表、表单、统计和审计内容使用实体白色面板与双层柔和阴影。
- 右侧详情面板和模态对话框使用更强的模糊与更深的双层阴影，并配合遮罩聚焦。
- 不在白色内容卡片上叠加玻璃效果，不堆叠多个浅色透明层。

## 4. 视觉系统

### 4.1 颜色

- 页面背景：`#f5f5f7`
- 内容表面：`#ffffff`
- 主文字：`#1d1d1f`
- 正文：`#424245`
- 次要文字：`#6e6e73`
- 三级文字：`#86868b`
- 分隔线：`rgba(0,0,0,0.07)`
- 主要动作：`#0071e3`；链接文字：`#0066cc`
- 在线/成功：`#30d158`
- 需要关注：`#ff6b00`

状态色必须限制在圆点、文字或小型胶囊内，不能成为大面积页面背景。

### 4.2 字体与数字

- 使用系统字体栈：`-apple-system`、`BlinkMacSystemFont`、`SF Pro Text`、`SF Pro Display`、`PingFang SC`、`Microsoft YaHei`。
- 根元素启用 `font-optical-sizing: auto` 和字体抗锯齿。
- 页面大标题采用响应式字号、紧凑行高和约 `-0.03em` 至 `-0.04em` 的负字距。
- 正文行高根据密度保持在 1.6–1.85；表格可更紧凑，但不能牺牲可读性。
- 任务数量、时间和耗时使用 `tabular-nums`。

### 4.3 圆角与阴影

- 胶囊按钮和筛选：`999px`
- 小标记：6–9px
- 小型内容块：12px
- 标准卡片：18px
- 统一面板：22px
- 路由详情面板：26px
- 普通面板和浮层均使用“接触阴影 + 扩散阴影”两层组合，不使用单个硬阴影。

### 4.4 图标

- 以本地内联 SVG 线性图标替换当前 `⌂`、`≡`、“日”等字符图标。
- 图标使用统一 24×24 视口、约 1.7px 线宽和 `currentColor`。
- 图标只承担识别或动作含义；不在标题、指标和每个单元格旁重复添加装饰图标。

## 5. 全站框架

### 5.1 桌面端

- 固定 224px 轻量侧栏，包含品牌、按权限过滤的导航和系统健康状态。
- 顶部 62px 浮动工具栏显示当前位置、今日值班和当前用户。
- 顶部栏只有在内容滚动到其下方时才出现滚动边缘渐变，不保留永久硬分隔线。
- 主内容最大宽度约 1160px，居中显示，使用响应式水平内边距。
- 详情面板打开时，背景内容轻微左移和缩小，保持空间关系但不影响阅读。

### 5.2 平板与窄桌面

- 侧栏收窄为 74px 图标轨道，保留提示文本和可访问名称。
- 低优先级表格列逐步隐藏，但流程编号、任务名称、状态和操作入口必须保留。

### 5.3 移动端

- 主导航改为最多四项的底部浮动栏：始终显示“工作台”和“任务中心”；第三项按角色优先显示“我要取号”（开发人员）、“人员管理”（非开发人员的组长）或“统计”（普通运维管理员）；存在其余获权路由时，第四项为“更多”，并在底部面板中列出剩余入口。组合角色按上述优先级只占用一个第三项入口。
- 所有两列布局改为单列；表格重排为列表行，不依赖横向滚动完成核心操作。
- 任务详情改为底部面板，最大高度约 88vh，保留拖动手柄和关闭按钮。

## 6. 路由联动任务详情

用户已确认任务详情采用“路由联动右侧面板”。

### 6.1 路由行为

- 点击工作台或任务中心的任务行后进入 `/tasks/:id`。
- Vue Router 中保留命名路由 `tasks` 和 `task-detail`；`task-detail` 的主路由组件仍渲染 `TaskQueuePage`，并通过路由元信息通知 `AppLayout` 挂载全局 `TaskDetailSheet`。因此详情不是与列表无关的第二套页面。
- 桌面端在任务中心背景上显示右侧详情面板；移动端显示底部详情面板。
- 从站内列表进入时，关闭面板优先执行 `router.back()`，返回原列表及原筛选状态。
- 直接访问或刷新 `/tasks/:id` 时，背景使用任务中心默认列表；关闭后替换到 `/tasks`，避免退出系统或进入空历史页。
- 浏览器前进/后退必须与面板开关保持同步。

### 6.2 数据行为

- 面板根据路由参数加载任务详情，沿用当前 `fetchTask`、任务操作和时间线接口。
- 切换到另一个任务时保留面板并更新内容，不重复执行完整进场动画。
- 加载中直接显示结构稳定的占位内容，不使用可能在异步重渲染时卡住的入场透明度关键帧。
- 加载失败在面板内显示错误与重试动作；不得自动关闭面板或清空背景列表。

### 6.3 手势和键盘

- 指针按下后使用 `setPointerCapture`，保存抓取偏移和最近约 90ms 的位置历史。
- 拖动越过关闭边界时应用渐进阻力；松手时使用释放速度投射终点，再选择关闭或回弹目标。
- 弹簧从面板当前展示值开始，并继承释放速度；动画过程中再次拖动应立即接管。
- `Escape`、遮罩、关闭按钮和关闭手势具有相同退出结果。
- 面板打开后焦点移入标题或首个操作；关闭后恢复到触发任务行。焦点不能逃到遮罩后的内容。
- 面板使用 `role="dialog"`、`aria-modal="true"`、可访问标题和加载状态。

## 7. 页面映射

### 7.1 登录与修改密码

- 登录页改为冷灰背景上的单一登录表面，品牌信息简洁呈现，不再使用大面积深海军蓝分栏。
- 输入框、错误信息和提交状态保持邻近映射；账号或密码错误在字段组内联展示。
- 修改初始密码使用最大 720px 的阅读/表单列，密码规则直接显示在对应字段附近。

### 7.2 工作台与任务中心

- 工作台顶部使用问候语和一句行动导向说明。
- 今日待执行、执行中、需要关注三个指标放在同一面板内，以细分隔线区分。
- 任务列表默认使用统一面板和行分隔线；任务行按下即时反馈，点击进入路由详情面板。
- 筛选使用分段控件加必要字段。高级筛选可折叠，但不能删除现有查询能力。
- 工作台保留“当天任务”语义；任务中心保留全量查询和分页。

### 7.3 新建任务

- 表单按“基本信息”“操作窗口”“补充说明”分组为连续面板行。
- 自动分配规则说明作为次要信息面板，不使用大面积深色装饰块。
- 提交按钮固定在表单动作区；校验失败就近显示并自动聚焦第一个错误字段。
- 分配结果使用成功状态行和明确负责人信息，不使用彩色左边框。

### 7.4 值班管理

- 导入、预览、确认三个阶段使用清晰的顺序提示，但不加入无功能的步骤动画。
- 文件选择区保持大触控目标；校验错误放在预览面板上方并可定位到对应行。
- 预览表和导入历史分别使用统一面板；导入确认属于不可轻易撤销操作，保留明确确认步骤。

### 7.5 人员与可用性

- 账号列表使用统一面板或表格，角色、可用状态和动作映射在同一行。
- 新建账号、设置不可用和批量重新分配采用右侧工作面板；真正阻塞且不可逆的操作才使用模态确认。
- 重新分配结果逐项展示成功、失败和人工处理入口，不用颜色填满整行。

### 7.6 统计

- 指标按业务关系组织在一个或少量统一表面内，避免每个数字成为单独卡片。
- 数字使用等宽数字形式；单位与口径紧邻指标。
- 筛选控件位于所影响报表上方；请求中保持旧结果并显示轻量更新状态。

### 7.7 审计日志

- 默认使用可扫描的统一日志列表，时间、操作者、动作和对象形成稳定列。
- JSON 或长字段按需展开为详情面板，不直接以深色大代码块占据主视图。
- 筛选失败、加载失败和无结果分别提供明确状态。

### 7.8 空状态、403 和占位页

- 使用简洁标题、原因说明和一个直接恢复动作。
- 不使用装饰性插画、Emoji 或虚构指标填充页面。

## 8. 反馈、错误与动作

- 四类反馈分别为：进行中、完成、警告、错误；文案必须说明对象和下一步。
- 可逆动作优先提供撤销；当前后端不支持撤销的动作不得伪造“撤销”按钮。
- 请求进行中只禁用会导致重复提交的具体按钮，不锁住整个页面或面板关闭能力。
- 成功反馈使用短暂浮动通知，并同步更新列表和顶部计数。
- 错误优先在相关表单或面板内联展示；通知只作为补充，不作为唯一错误载体。
- 确认对话框仅用于停用账号、确认导入等不可轻易恢复的操作。

## 9. 前端结构

### 9.1 样式拆分

保留 `frontend/src/styles.css` 作为样式入口，并拆分为：

- `frontend/src/styles/tokens.css`：颜色、字体、圆角、阴影、层级和动效参数。
- `frontend/src/styles/base.css`：重置、页面背景、排版、焦点和无障碍基础规则。
- `frontend/src/styles/layout.css`：侧栏、顶部栏、内容容器和响应式框架。
- `frontend/src/styles/components.css`：按钮、面板、表单、表格、状态、通知和浮层。

页面只使用语义类和令牌，不在 Vue 模板中新增散落的颜色、阴影或动效常量。

### 9.2 组件边界

- `AppLayout.vue`：全站框架、响应式导航、滚动边缘和全局详情面板插槽。
- `RoleNavigation.vue`：权限过滤、SVG 图标和当前路由状态。
- 新增 `TaskDetailSheet.vue`：路由详情加载、焦点管理、遮罩和操作区。
- 新增 `useRouteSheet.ts`：打开/关闭、返回策略、直接访问回退和焦点恢复。
- 新增 `useSpringSheet.ts`：Pointer Events、速度历史、阻力、终点投射和可中断弹簧。
- 现有 `TaskDetailPage.vue` 的业务展示逻辑拆入 `TaskDetailContent.vue` 并由 `TaskDetailSheet.vue` 使用；路由迁移和测试通过后删除不再被引用的独立页壳，不复制 API 调用或任务操作逻辑。
- 现有通知、重新分配和不可用对话框统一使用相同浮层材质、焦点规则和进出路径。

不新增完整 UI 框架。弹簧和拖动使用小型 TypeScript composable 实现，避免为单一面板引入大体积运行时依赖。

## 10. 动效参数与降级

- 普通按压：约 100ms，即时缩放至 0.965–0.98。
- 普通悬停：150–220ms，只改变表面或产生不超过 3px 的位移。
- 非手势面板进场：临界阻尼，无弹跳，响应约 0.35–0.4s。
- 拖动释放：允许轻微动量感，响应约 0.3–0.4s；只有手势带来速度时才允许轻微越界回弹。
- 每帧只更新 `transform` 和 `opacity`；拖动期间使用 `requestAnimationFrame`。
- `prefers-reduced-motion: reduce` 下取消滑动、缩放和弹簧，以短交叉淡化或即时状态替代。
- `prefers-reduced-transparency: reduce` 下将侧栏、顶栏和面板变为接近实体的背景并关闭模糊。
- `prefers-contrast: more` 下提高背景不透明度、边界和焦点轮廓对比度。

## 11. 测试与验收

### 11.1 自动化验证

- 现有 Vitest 用例全部通过。
- `vue-tsc --noEmit` 和 Vite 生产构建通过。
- 路由测试覆盖 `/tasks`、站内打开 `/tasks/:id`、直接访问、刷新、返回和关闭回退。
- 组件测试覆盖详情加载、错误重试、Escape、遮罩、关闭按钮、焦点恢复和请求中可关闭。
- composable 测试覆盖拖动阈值、释放速度方向、投射终点、阻力和减少动态效果分支。
- 现有 Playwright 业务流程继续通过，任务详情定位器按新面板结构更新。

### 11.2 浏览器验收

- 至少使用 1440×900、1024×768 和 390×844 三种视口检查登录、工作台、任务中心、任务详情、任务创建、值班、人员、统计和审计。
- 桌面任务详情从右侧进入，移动端从底部进入；浏览器前进/后退和直接 URL 行为正确。
- 在动画中再次拖动面板没有跳变；关闭后焦点返回触发任务行。
- 320px 宽度无关键操作被裁切；核心流程不依赖横向滚动。
- 所有可点击目标至少 44px，键盘焦点清晰，文本在 200% 缩放下仍可完成任务。
- 减少动态效果、减少透明度和高对比度三种媒体偏好分别验证。
- 页面整体与已确认的 `apple-design-fluid-v2.html` 原型保持同一视觉和交互语言。

## 12. 完成标准

只有同时满足以下条件，才可声明全站重构完成：

1. 本规格所列全部页面和交互层均已迁移，不存在明显旧主题残留。
2. 原有业务行为、权限和 API 调用没有回归。
3. 路由联动任务详情、拖动关闭、历史导航和直接访问全部可用。
4. 自动化测试、类型检查和生产构建通过。
5. 桌面、平板和移动端完成实际浏览器检查并保存验证记录。
6. 无障碍媒体偏好和键盘路径完成验证。
